# Pós-Engenharia de IA Aplicada

Repositório com os exemplos, exercícios e códigos produzidos ao longo da pós-graduação.

## Estrutura

Cada disciplina/módulo tem uma pasta numerada na raiz. Dentro de cada uma, os exemplos também são numerados na ordem em que foram feitos:

```
01-nome-da-disciplina/
  01-nome-do-exemplo/
    README.md
    (código do exemplo)
  02-outro-exemplo/
    README.md
    (código do exemplo)
02-outra-disciplina/
  ...
```

Use `00-exemplo-modelo/` como referência de como estruturar uma nova pasta de exemplo.

## Convenção para cada exemplo

- Uma pasta por exemplo, com nome curto descrevendo o que ele faz.
- Um `README.md` dentro explicando: o que é, contexto/enunciado do exercício (se houver) e como rodar.
- Commits pequenos e frequentes — um commit por exemplo/exercício facilita achar depois.
